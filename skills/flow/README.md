# flow/

Everything here works whether or not there's a repo underneath you — planning a launch, writing an article, prepping for a meeting, same as shipping a feature.

**User-invoked** (typed, never auto-fired):

- **[interrogate](./interrogate/SKILL.md)** — relentless interview about a plan or design, until every open branch closes
- **[relay](./relay/SKILL.md)** — compress this conversation into a document another agent can pick up cold
- **[mentor](./mentor/SKILL.md)** — teaches you something over several sessions, using the working directory as the notebook
- **[envoy](./envoy/SKILL.md)** — turns a question you can't answer alone into a questionnaire aimed at the person who can
- **[clarify](./clarify/SKILL.md)** — the message didn't land; re-pitch it in plain terms, right now, mid-conversation

**Model-invoked** (either of you):

- **[interview](./interview/SKILL.md)** — the raw interrogation primitive underneath `interrogate` and `cross-examine` both
- **[styleguide](./styleguide/SKILL.md)** — how to write anything meant for an agent to read: skills, AGENTS.md, pointer docs
